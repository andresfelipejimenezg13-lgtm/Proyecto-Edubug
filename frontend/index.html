HTML es la base de una página web

HTML es el lenguaje que utilizamos para crear y organizar el contenido de una página web. Podemos verlo como el "esqueleto" de una página.

Con HTML podemos colocar títulos, textos, imágenes, enlaces, listas y otros elementos que forman una página.

Ejemplo:

<p>Hola, este es mi primer texto.</p>

Etiqueta: <p>
Contenido: Hola, este es mi primer texto.
Elemento completo: <p>Hola, este es mi primer texto.</p>

¿Cómo se organiza un documento HTML?

Un documento HTML tiene una estructura que organiza el contenido de la página. Algunas partes son necesarias para indicar al navegador cómo interpretar el documento.

Ejemplo:

<!DOCTYPE html>
<html>
  <head>
    <title>Mi página</title>
  </head>
  <body>
    <h1>Hola Mundo</h1>
  </body>
</html>

<!DOCTYPE html> indica que estamos trabajando con HTML5.

<html> contiene todo el documento. Dentro encontramos principalmente head y body.

<head> contiene información de la página, mientras que <body> contiene el contenido que podemos ver directamente en el navegador.

¿Qué son los atributos?

Los atributos permiten agregar información o características a una etiqueta HTML. Se escriben dentro de la etiqueta de apertura y ayudan a indicar cómo debe funcionar o comportarse un elemento.

Ejemplo:

<a href="https://www.google.com">Ir a Google</a>

Etiqueta: <a>
Atributo: href
Valor: "https://www.google.com"

¿Cómo se escribe un atributo?

La forma básica de escribir un atributo es:

clave="valor"

Es importante utilizar el signo = y colocar el valor entre comillas.

Por ejemplo, en href="https://www.google.com", href es la clave y "https://www.google.com" es el valor.

Etiquetas para crear contenido

Las etiquetas HTML permiten crear y organizar los diferentes elementos que aparecen en una página web. Cada una tiene una función diferente.

Texto

Para crear títulos podemos utilizar las etiquetas <h1> hasta <h6>. Para escribir párrafos utilizamos <p>.

<h1>Mi página web</h1>
<p>Este es mi primer párrafo.</p>
Enlaces e imágenes

La etiqueta <a> permite crear enlaces hacia otras páginas. La etiqueta <img> permite mostrar imágenes.

<a href="https://www.google.com">Google</a>

<img src="imagen.jpg" alt="Mi imagen">
Listas

También podemos crear listas. La etiqueta <ul> crea una lista sin orden y <ol> crea una lista numerada.

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

Evita errores al escribir HTML

Cuando estamos aprendiendo HTML es normal cometer algunos errores. Lo importante es aprender a identificarlos y corregirlos.

1. No cerrar una etiqueta

Algunas etiquetas necesitan una etiqueta de cierre. Por ejemplo:

Correcto:
<p>Hola mundo</p>

Incorrecto:
<p>Hola mundo
2. No cerrar las comillas

Cuando utilizamos atributos, debemos escribir correctamente las comillas del valor.

Correcto:
<img src="imagen.jpg">

Incorrecto:
<img src="imagen.jpg>
3. Ordenar correctamente las etiquetas

Cuando utilizamos varias etiquetas debemos respetar el orden en el que se abren y se cierran.

Correcto:
<p><strong>Hola</strong></p>

Incorrecto:
<p><strong>Hola</p></strong>
Una buena práctica

Mantener el código ordenado y utilizar una buena indentación facilita encontrar errores y entender lo que estamos haciendo.
